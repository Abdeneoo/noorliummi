# نور لأمي — ذكّرني (إضافة كروم)

مواقيت الصلاة والعدّ التنازلي، الأذان عند كل صلاة وتنبيه قبلها، تذكير الورد اليومي حتى تكمله، تذكير بالأذكار (الاستغفار، التسبيح، الصلاة على النبي ﷺ — من «حصن المسلم» بتخريجها)، تذكير صيام الإثنين والخميس والأيام البيض (مع استثناء العيدين وأيام التشريق ورمضان)، تذكير الكهف يوم الجمعة، ووضع النوم وكتم ساعة.

- المواقيت تُحسب على الجهاز بمحرك الموقع نفسه (Adhan JS، MIT) مع المناطق الزمنية والتوقيت الصيفي.
- الأذان يُبث من موقع نور لأمي (تسجيلات مستضافة بترخيص موثّق؛ القائمة من `/api/v1/adhans`)، ولا يُضمّن صوت داخل الإضافة.
- لا تتبع، لا معرّفات، لا جمع بيانات. الطلبات الوحيدة: قائمة الأذان، ملف الأذان عند التشغيل، وآية اليوم — كلها من الموقع.
- الخادم الحالي: Staging (`lib/config.js` → `BASE`). يُغيَّر إلى الدومين الرسمي بعد موافقة الإطلاق.

البناء: `node build.mjs` (يجمع محرك المواقيت ويولّد قائمة الأذكار ويضع ملف zip في `apps/web/public/extension/`).
التجربة: chrome://extensions ← وضع المطوّر ← «تحميل غير مُعبّأ» ← اختر هذا المجلد.
