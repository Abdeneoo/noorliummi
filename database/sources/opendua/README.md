# OpenDua — Hisn al-Muslim dataset v0.0.4 + recordings v0.0.2
- Data: https://opendua.hdfund.org/v0.0.4/catalogue.json (verbatim here, SHA256 in SHA256SUMS). Licence: CC BY 4.0 for OpenDua's translation, transliteration, metadata and structure; OpenDua claims no rights in the religious text.
- Audio: https://audio.opendua.org/hisn/v0.0.2/opendua-audio-hisn-v0.0.2.zip (SHA256 in AUDIO_SHA256). Licence: CC BY 4.0 (https://opendua.hdfund.org/licence/audio) — self-hosting, redistribution and re-encoding permitted. The v0.0.2 archive README says the data licence does not cover recordings; the licence page (checked 2026-11-25) withdraws that and states the audio licence (CC BY 4.0) governs.
- Required credit: "Recitation by Muhammad Jumah for OpenDua." + licence link; no suggestion of endorsement by OpenDua, Ihsan Labs or the Human Development Fund.
- Use on the site: a recording is attached to one of our Hisn al-Muslim entries (asellam/HisnElMuslim) ONLY when the Arabic text matches exactly after removing diacritics/punctuation (189 of 302 on 2026-11-25; spacing between words is ignored, letters must be identical). Audio files are not stored in Git; `infrastructure/fetch-opendua-audio.sh` downloads the pinned zip and verifies its checksum.
