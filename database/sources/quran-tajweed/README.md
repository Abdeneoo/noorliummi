# Tajweed annotations — cpfair/quran-tajweed (CC BY 4.0), mapped onto our Tanzil text
- Source data: https://github.com/cpfair/quran-tajweed (commit in SOURCE_COMMIT), `output/tajweed.hafs.uthmani-pause-sajdah.json`, licensed **CC BY 4.0** (Collin Fair). Riwayat Hafs. Built from ReciteQuran.com, Dar al-Maarifah tajweed masahif and others (per the project README). Automatic, not reviewed by a teacher.
- Its offsets refer to the Tanzil Uthmani text of ca. 2017, linked from the project README; that file (`quran-uthmani-2017.txt`, Tanzil, verbatim) was supplied by the project owner on 2026-11-25. Check: the published annotations pass the letter-signature checks on it with 0 errors (19,819 checked).
- `scripts/map-tajweed.py` aligns each 2017 ayah with our Tanzil ayah character by character. 5,816 ayat are identical; 420 differ only in encoding (ء → ـٔ in 277 places, small yaa ۦ → ـۧ in 38, basmala separated from the first ayah, a few spaces). An annotation is kept only if all its characters are unchanged: 60,023 kept, 34 dropped. Final checks on our text: 0 out-of-range, 0 signature failures (hamzat al-wasl on ٱ, qalqalah on ق ط ب ج د, lam shamsiyyah on ل).
- `tajweed-mapped.json` is the result (derived data, CC BY 4.0, attribution Collin Fair). The Quran text itself is never changed; colours are only spans around unchanged characters.
- No annotations are shown for the separated basmala.
