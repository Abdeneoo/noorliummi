# QuranEnc — arabic_moyassar (التفسير الميسر، مجمع الملك فهد) — ayat of prophets' duas
- Source: `https://quranenc.com/api/v1/translation/aya/arabic_moyassar/{sura}/{aya}`, fetched 2026-11-26. Verbatim.
- Terms (quranenc.com): no modification, addition or deletion; name the publisher and QuranEnc.com as source.
- `prophets.json`: the owner's reference list (26 Nov 2026) plus the duas the Prophet ﷺ was commanded to say. An item is kept only if the
  tafsir of the ayah — or, when the ayah does not name him, of the preceding ayat of the same passage (`context`) — names the prophet.
  All 41 items passed. `kind`: said (قاله النبي) / joint (قاله أكثر من واحد) / commanded (أُمر بقوله).
- `1.json … 114.json`: the full Tafsir al-Muyassar per surah (`/api/v1/translation/sura/arabic_moyassar/{n}`), fetched 2026-11-26, verbatim (6,236 ayat). Shown under each ayah in /tafsir and in the mushaf's tafsir panel, as an authorised source for the meanings of the ayat (including their unusual words) until «السراج في بيان غريب القرآن» is permitted.
