# ملفات المراجعة الشرعية

ملفات جاهزة للإرسال إلى أهل العلم. المراجعة الشرعية يقوم بها إنسان متخصص فقط؛ الاختبارات الآلية وفحوص الذكاء الاصطناعي ليست مراجعة.

| الملف | لمن | المطلوب |
|---|---|---|
| `INHERITANCE_CASES.md` | متخصص في الفرائض | التحقق من ٢٣ مسألة: الأنصبة والأسباب والحالات المرفوضة |
| `SECTIONS.md` | مراجع عام | قائمة الأقسام ومصدر كل قسم وما يحتاج نظرًا خاصًا |

بعد المراجعة: يسجّل صاحب المشروع في لوحة التحكم (تبويب «المراجعة والبث») حالة القسم واسم المراجع والتاريخ، فتظهر في «تقرير الشفافية». الحالات الأربع: موثّق المصدر · بانتظار المراجعة البشرية · راجعه متخصص · يحتاج تعديلًا.

جهات رسمية يمكن مراسلتها للمراجعة أو الاستفتاء: الأزهر الشريف (azhar.eg)، دار الإفتاء المصرية (dar-alifta.org)، الرئاسة العامة للبحوث العلمية والإفتاء (alifta.gov.sa).
