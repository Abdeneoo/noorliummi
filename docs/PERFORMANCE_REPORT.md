## ما أُصلح
- **الوصول 93/96 → 100** في كل الصفحات: أسماء الأزرار تطابق نصها الظاهر (حجم الخط، تبديل اللغة، علامات الآيات، عدّاد الذكر، المسبحة).
- الرئيسية: صورة الشعار بمقاس 360 بكسل للموبايل (بدل 480)، إلغاء حركة «التوهّج» على الشعار، إيقاف حركات الخلفية والـ backdrop-filter على الموبايل، وعدم تحميل ملف دعاء الأم الصوتي إلا عند الضغط. LCP محليًا 10.8 → 7.1 ث، وTBT 1460 → 850.
- صفحة الدروس: تثبيت شبكة «أبرز الأبواب» (CLS 0.24 → 0.03).
- صفحة الأسرة: لا خطأ في الـ console للزائر غير المسجّل (أفضل الممارسات 96 → 100).

## ما لم يتحقق ولماذا
- **هدف الأداء ≥ 90 لم يتحقق.** المتبقي: زمن تنفيذ JavaScript عند فتح الصفحة (hydration لمكوّنات الرأس والأذان والمشغّل) وتأخر أول رسم. جُرّب تضمين CSS داخل الصفحة (`inlineCss`) فلم يُحسّن FCP وسبّب إزاحة في الرئيسية فأُلغي.
- **SEO 66–69 مقصود**: Staging عليه `noindex` بقرار صاحب المشروع حتى الإطلاق، ولن يُزال لرفع الرقم. بعد الإطلاق (NOOR_PUBLIC=1) يزول هذا الخصم.
- الخطوة التالية المقترحة: تأجيل تحميل مكوّنات الأذان والمشغّل حتى أول تفاعل، ثم إعادة القياس على Staging نفسه.
