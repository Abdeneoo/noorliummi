# تسليم: تطبيق أندرويد لـ «نور لأمي» (Noor Li Ummi)

> انسخ هذا الملف كاملًا لـ Claude Code كأول رسالة في مشروع التطبيق. آخر تحديث: 26 نوفمبر 2026، بعد الإطلاق على الدومين الرسمي.

## 1) ما هو المشروع
- منصة إسلامية مجانية غير ربحية، **صدقة جارية عن روح «أمل مجدي منير»** (والدة صاحب المشروع). اسمها يظهر في شاشة «عن التطبيق» وشاشة الإهداء ووصف المتجر مع طلب الدعاء لها.
- الموقع الرسمي: https://noorliummi.io — بيئة الاختبار: https://staging.noorliummi.io
- الكود (عام، AGPL-3.0): https://github.com/Abdeneoo/noorliummi. اقرأ قبل البدء: `CLAUDE.md`، `docs/DATA_SOURCES.md`، `docs/CONTENT_LICENSES.md`، `docs/DESIGN_SYSTEM.md`، ومجلد `apps/extension` (إضافة كروم: نفس منطق التذكيرات المطلوب في التطبيق).
- تواصل صاحب المشروع: https://www.facebook.com/3abdeneo

## 2) قواعد لا تُكسر
1. **نص القرآن لا يُعدَّل أبدًا** (Tanzil Uthmani، CC BY 3.0، مع ذكر المصدر).
2. لا نص ديني مولَّد بالذكاء الاصطناعي، ولا ترجمة آلية لمحتوى ديني، ولا فتوى آلية. كل نص ديني من مصدر موثق في `DATA_SOURCES` ويُعرض كما هو.
3. **لا تتبع ولا تحليلات ولا إعلانات ولا جمع بيانات** (لا Firebase Analytics/Crashlytics ولا أي SDK إعلاني). نموذج Data safety = «لا يجمع بيانات».
4. لا عدّادات أجر/ثواب. التسجيلات الصوتية للمستخدم تبقى خاصة.
5. لا أسرار في Git: ملف التوقيع وكلماته في GitHub Secrets أو عند المالك. لا تطلب كلمات مرور في المحادثة.
6. لا خدمات مدفوعة دون موافقة المالك (حساب Google Play Developer رسومه 25$ مرة واحدة — يفتحه المالك بنفسه).
7. المستودع عام: لا IP ولا أسماء مواقع المالك الأخرى ولا بيانات شخصية في أي ملف.
8. لا تلمس السيرفر ولا الإنتاج. أي تغيير في الموقع/الـAPI: PR → اختبار على staging → موافقة المالك.

## 3) القرار التقني
**تطبيق هجين: أصلي Kotlin + Jetpack Compose للمزايا اليومية، والموقع داخل WebView للمكتبة الكبيرة.**
- minSdk 26، targetSdk = أحدث ما يطلبه المتجر.
- **أصلي (يعمل بلا إنترنت):** المواقيت، الأذان والتنبيهات، القبلة، التذكيرات، عدّاد التسبيح، الأذكار اليومية (تُخزَّن بعد أول تحميل)، الويدجت.
- **WebView** مقيد بنطاق `noorliummi.io` فقط (الروابط الخارجية تُفتح في المتصفح): المصحف والتفسير والحديث والفقه والكتب والمكتبة والسلاسل والدروس والأدعية والحساب والأسرة. هكذا يبقى التطبيق مطابقًا للموقع دون نسخ المحتوى أو تكرار تراخيصه.
  - فعّل JavaScript وDOM storage والكوكيز (الحساب يعمل بكوكي جلسة الموقع)، وزر الرجوع يرجع في سجل الـWebView.
  - لا تحقن أي JavaScript تتبعي. يمكن إضافة `?app=1` لاحقًا إن احتجنا تخصيص العرض (يتطلب PR على الموقع).
- المواقيت بمكتبة Adhan الرسمية (`com.batoulapps.adhan:adhan2`، MIT) — نفس المحرك المستخدم في الموقع والإضافة (`packages/prayer-engine` على Adhan JS). اكتب اختبارات تطابق أوقات 3 مدن مع `GET /api/v1/times`.
- التخزين محلي فقط: DataStore للإعدادات، Room للورد والتقدم.

## 4) الشاشات الأصلية
| الشاشة | التفاصيل |
|---|---|
| الرئيسية | الصلاة القادمة + عدّ تنازلي، التاريخ الهجري، آية اليوم وحديث اليوم، اختصارات للأقسام |
| الأذان والتنبيهات | الأذان عند الوقت + تنبيه قبل الصلاة بدقائق يختارها المستخدم. `AlarmManager.setExactAndAllowWhileIdle` مع إذن `SCHEDULE_EXACT_ALARM` (اطلبه بشرح؛ لا تستخدم `USE_EXACT_ALARM`)، `POST_NOTIFICATIONS`، وأعد الجدولة بعد `BOOT_COMPLETED` وتغيير الوقت/المنطقة. اشرح للمستخدم استثناء توفير البطارية |
| أصوات الأذان | من `GET /api/v1/adhans` (كل صوت بترخيصه ومصدره). تُنزَّل عند اختيار المستخدم، وتُعرض بيانات الترخيص |
| القبلة | الاتجاه من الإحداثيات (Adhan `Qibla`) + البوصلة من الحساسات مع تنبيه المعايرة |
| الموقع | يدوي (قائمة مدن) أو موقع الجهاز `ACCESS_COARSE_LOCATION` عند الطلب فقط؛ لا يُرسل لأي خادم. اقتراح طريقة الحساب حسب الدولة كما في `nearestMethod` بـ `apps/extension/src/engine.ts` |
| الإعدادات | طريقة الحساب، مذهب العصر (الجمهور/الحنفي)، تعديل دقائق لكل صلاة |
| التذكيرات | الورد اليومي (يتكرر حتى «تم»)، أذكار الصباح والمساء، الاستغفار والصلاة على النبي ﷺ، صيام الاثنين والخميس والأيام البيض (تُستثنى رمضان و1 شوال و10–13 ذو الحجة كما في `fastReason`)، الكهف يوم الجمعة، الضحى، قيام الليل (الثلث الأخير)، وضع النوم يوقف غير الأذان |
| عدّاد التسبيح | الأذكار الستة كما في `apps/web/src/lib/dhikr-phrases.ts`. الهدف: **33 (افتراضي) / 70 / 100**. **الصلاة على النبي ﷺ: عدد مفتوح بلا هدف**. اهتزاز عند اكتمال الهدف. العدد على الجهاز فقط |
| الأذكار | نصوص حصن المسلم من `GET /api/v1/adhkar?chapter=27` (الصباح)، `28` (المساء)، `29` (النوم)، تُخزَّن محليًا |
| الويدجت | الصلاة القادمة والعدّ التنازلي (Glance) |
| عن التطبيق | الإهداء لأمل مجدي منير، المصادر والتراخيص (رابط `/sources`)، الخصوصية (`/privacy`)، رابط التواصل |

## 6) الحساب
- الموقع يستخدم تسجيلًا عاديًا بالبريد وكلمة المرور (كوكي جلسة `HttpOnly` لمدة 60 يومًا). **لا يوجد API مصادقة للتطبيقات الأصلية**، فشاشة الحساب تُفتح في الـWebView ويحتفظ الـWebView بالكوكي.
- لا تخزّن كلمة المرور في التطبيق، ولا تقرأ الكوكي من كود أصلي.
- ركن الأطفال: الجهاز الذي يحمل جلسة طفل لا يصل إلا إلى `/kids` (يفرضه الخادم). لا تتجاوز ذلك في التطبيق.

## 7) الـ API العام (للقراءة فقط، بلا مفتاح)
القاعدة `https://noorliummi.io/api/v1/` — CORS مفتوح، **حد 120 طلبًا/ساعة لكل IP**: خزّن النتائج يوميًا ولا تستعلم في حلقة.
- `ayah-of-day?date=YYYY-MM-DD`
- `hadith-of-day?date=YYYY-MM-DD`
- `adhkar?chapter=27`
- `times?city=makkah&date=...` (للاختبار والمقارنة فقط؛ الحساب الفعلي على الجهاز)
- `adhans`
أي endpoint جديد (مثلًا فهرس الفقه أو الأدعية بصيغة JSON للعمل بلا إنترنت): PR على المستودع، يُختبر على staging، ولا يُنشر إلا بموافقة المالك.

## 8) الهوية والواجهة
- عربي أولًا مع RTL كامل، ثم الإنجليزية.
- الألوان: الأخضر الداكن `#103D32` (theme)، الخلفية `#0B1F19`، الذهبي للتمييز. الخطوط والتفاصيل في `docs/DESIGN_SYSTEM.md` و`docs/BRAND_GUIDELINES.pdf`. الأيقونات في `apps/web/public` (`icon-512.png`، `icon.svg`).
- إمكانية الوصول: TalkBack، أحجام خط ديناميكية، تباين AA، أهداف لمس 48dp.

## 9) النشر
- اسم الحزمة المقترح: `io.noorliummi.app`.
- AAB يُبنى بـ GitHub Actions، والتوقيع من Secrets. نسخة اختبار داخلي أولًا، والمالك يرفعها بنفسه.
- لاحقًا (اختياري): Digital Asset Links على `https://noorliummi.io/.well-known/assetlinks.json` لفتح روابط الموقع في التطبيق — تحتاج PR وموافقة.
- سياسة الخصوصية: `https://noorliummi.io/privacy`.
- الترخيص AGPL-3.0 مثل المشروع.

## 10) تعريف «تم»
- اختبارات وحدة للمواقيت (مطابقة الـAPI)، والجدولة بعد إعادة التشغيل، ومنطق الصيام، وأهداف التسبيح.
- تجربة على جهاز حقيقي بأندرويد 14 أو أحدث مع توفير البطارية: الأذان يرن في وقته والشاشة مقفلة.
- تقرير صادق بما نجح وما لم ينجح. لا شيء يُنشر في المتجر دون موافقة المالك.
