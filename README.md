# نور لأمي | Noor Li Ummi

> نورٌ لا ينطفئ، وأثرٌ لا ينقطع.

منصة إسلامية مجانية غير تجارية، بلا إعلانات ولا تتبّع، أُنشئت صدقةً جارية. العربية أولًا.

**ما فيها الآن (نسخة تجريبية):** المصحف بالرسم العثماني (Tanzil، دون أي تعديل ومحمي باختبارات)، تفسير الجلالين، التلاوة بثًّا من مصدرها، المتشابهات، مواقيت الصلاة والقبلة محسوبة على جهاز المستخدم، الأذان، أذكار حصن المسلم مع تسجيلات صوتية، كتب الحديث الستة والموطأ والأربعينات مع البحث، وصفحات «الأثر» لإهداء القراءة.

## مبادئ لا تتغير
- نص القرآن لا يُعدَّل أبدًا، ويُتحقق منه آليًا عند كل بناء.
- لا نصوص دينية مولَّدة بالذكاء الاصطناعي. كل نص من مصدر مسمّى بترخيصه.
- لا يُستخدم مصدر قبل التحقق من ترخيصه: [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md).
- الخصوصية: الموقع والمواقيت تُحسب على الجهاز، ولا حسابات إلزامية.

## التشغيل
```bash
pnpm install
bash infrastructure/fetch-hadith.sh          # نصوص الحديث (مثبّتة بالبصمات)
bash infrastructure/fetch-opendua-audio.sh   # تسجيلات الأذكار (اختياري)
pnpm test
pnpm --filter @noor/web build && pnpm --filter @noor/web start
```
صفحات «الأثر» تحتاج PostgreSQL ومتغير `DATABASE_URL` (انظر `infrastructure/`).
